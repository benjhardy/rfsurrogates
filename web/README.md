# web: the browser page

| file | what it is |
|---|---|
| `index.html` | the page: sliders, response plot, 3D layout, inverse design, Palace references, contributor commands |
| `surrogate.js` | dependency-free port of the family prior, the DeepONet forward pass, the metrics, the clearance rule and the copper layout (`Surrogate.layout`) |
| `rfscene.js` | reusable 3D view of a layered RF device (below) |
| `check_port.mjs` | `node check_port.mjs`: JavaScript vs Python on 24 random designs (prior, networks, layout) |
| `palace_refs.json` | Palace curves of six designs |
| `weights.json`, `check_ref.json` | generated by `core/export_web.py` (not in git; `weights.json` is also in the Hugging Face model repo) |

Serve the folder with any static server, for example `python -m http.server --directory web`.

## rfscene.js

A small 3D viewer for planar and layered devices, written to be copied into other projects (filters, couplers, coil
builders). It needs three.js r128 and its OrbitControls, loaded before it:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/controls/OrbitControls.js"></script>
<script src="rfscene.js"></script>
```

```js
if (RFScene.supported()) {
  const view = RFScene.create(document.querySelector('#stage'), { toolbar: document.querySelector('#tools'), buttonClass: 'btn' });
  view.setDevice({
    layers: [
      { id: 'ground', kind: 'ground', z0: -0.035, z1: 0, shapes: [{ rect: [-3, -6, 41, 11] }] },
      { id: 'substrate', kind: 'dielectric', z0: 0, z1: 0.508, shapes: [{ rect: [-3, -6, 41, 11] }] },
      { id: 'copper', kind: 'metal', z0: 0.508, z1: 0.543, shapes: [{ rect: [0, -0.44, 8.56, 0.44], tags: ['w1'] }] },
    ],
    ports: [{ name: 'Port 1', at: [-3, 2.5, 4.25], size: [17, 8.5], normal: 'x' }],
  });
  view.highlight('w1');                       // everything tagged w1 lights up
  view.setSignal({ s11: 0.1, s21: 0.95 });    // port pulses sized by |S11| and |S21|
}
```

Call `setDevice` again with new numbers and the shapes glide to the new geometry; the camera stays where the user
put it. Shapes: `rect` (axis-aligned box), `poly` (extruded polygon), `cyl` (cylinder along x, y or z). Layer kinds:
`metal`, `ground`, `dielectric` (translucent), `outline` (edges only, for an air box), `marker` (hidden until its tag
is highlighted). Other calls: `frame()`, `top()`, `setExplode(0 | 1)`, `setAutoRotate(bool)`, `setPlaying(bool)`,
`tint(layerId, colour | null)`, `setColors({...})` for a theme change. The full description format is at the top
of `rfscene.js`. It renders only while something moves, pauses off screen, follows `prefers-reduced-motion`, and on
touch screens the page scrolls until the user taps "Turn".
